# SpringAI-Jev

Design-stage portfolio project for learning Java 25, Spring Boot, Spring AI, Jev, JWT authentication, and PostgreSQL.

The planned application is an API for submitting software issues, making structured triage decisions with Jev, and drafting maintainer replies with Spring AI and a local Ollama model. No application implementation is present yet.

See [the design specification](docs/superpowers/specs/2026-10-10-issue-triage-api-design.md) for the agreed first-version scope.
